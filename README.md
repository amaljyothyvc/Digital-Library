# Digital-Library
A website that allows you to store information about digital book.Done in both Front End and backend.

✨ Features
User registration
Username and email validation
Password confirmation
Secure password hashing with bcrypt
Add books to your personal library
Store book title, author, pages, and reading status
Load books from the database
Separate books based on the registered user
Responsive design for desktop, tablet, and mobile
SQLite database for persistent storage

🛠️ Tech Stack
Frontend
HTML5
CSS3
JavaScript
DOM Manipulation
Fetch API

Backend

Node.js
Express.js
CORS
bcrypt

Database
